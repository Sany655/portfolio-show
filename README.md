# DAD Home — Luxury Interior Design Website

A responsive React + Vite website inspired by the supplied reference image.

## Run locally
1. Install Node.js (LTS) if it is not installed.
2. Open this folder in Antigravity.
3. Open the integrated terminal and run:
   ```bash
   npm install
   npm run dev
   ```
4. Open the local URL printed by Vite.
5. For a production build run `npm run build`.

## Before publishing
- In `src/main.jsx`, replace `WHATSAPP_NUMBER` with your real WhatsApp number in international format, digits only.
- Replace demo brand name, phone number, email, and location with the client's actual details.
- Replace the sample Unsplash images with licensed project photography.
- Connect the contact form to a backend or CRM if you want to store enquiries. Currently it prepares the enquiry and opens WhatsApp.
- Add your own favicon, legal/privacy pages, analytics and SEO details.
